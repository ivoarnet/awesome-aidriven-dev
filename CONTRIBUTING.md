# Contributing to Awesome AI-Driven Development

Thank you for your interest in contributing! This guide will help you get started.

## How to Contribute

There are many ways to contribute to this awesome list:

- Add new tools, resources, or learning materials
- Improve existing descriptions
- Fix broken links
- Suggest new categories or sections
- Report issues with existing entries
- Improve documentation and examples

## Contribution Guidelines

### Quality Standards

To maintain the quality of this list, please ensure your contributions meet these criteria:

1. **Relevance**: The resource should be directly related to AI-driven development
2. **Quality**: The tool/resource should be well-maintained and useful
3. **Accessibility**: Include both free and paid options, clearly marked
4. **Active**: The project should be actively maintained (updated within the last year)
5. **Description**: Provide a clear, concise description (1-2 sentences)
6. **Unique**: Avoid duplicates - check if the resource is already listed

### Formatting

- Use consistent formatting with the rest of the list
- Keep descriptions brief and informative
- Use proper Markdown syntax
- Test all links before submitting
- Follow alphabetical order within sections when appropriate

### Entry Format

```markdown
- [Tool Name](https://example.com) - Brief description of what it does (max 2 sentences).
```

Example:
```markdown
- [GitHub Copilot](https://github.com/features/copilot) - AI pair programmer that suggests code in real-time.
```

## Submission Process

1. **Fork the Repository**
   ```bash
   # Click the "Fork" button on GitHub or use:
   gh repo fork ivoarnet/awesome-aidriven-dev
   ```

2. **Create a Branch**
   ```bash
   git checkout -b add-your-feature
   ```

3. **Make Your Changes**
   - Add your contribution to the appropriate section
   - Ensure proper formatting
   - Test all links

4. **Commit Your Changes**
   ```bash
   git add .
   git commit -m "Add [Resource Name] to [Section]"
   ```
   
   Use clear, descriptive commit messages:
   - ✅ "Add Cursor IDE to AI-Powered IDEs section"
   - ✅ "Fix broken link for Tabnine"
   - ✅ "Update GitHub Copilot description"
   - ❌ "Update README"
   - ❌ "Changes"

5. **Push to Your Fork**
   ```bash
   git push origin add-your-feature
   ```

6. **Open a Pull Request**
   - Go to the original repository
   - Click "New Pull Request"
   - Select your branch
   - Fill in the PR template with details about your contribution

## Pull Request Guidelines

### PR Title Format

Use clear, descriptive titles:
- `Add [Tool Name]`
- `Update [Section Name]`
- `Fix broken link in [Section]`
- `Remove outdated [Resource Name]`

### PR Description

Include in your PR description:
- What you're adding/changing
- Why this resource is valuable
- Any relevant context or notes
- Confirmation that you've tested the links

Example:
```markdown
## Changes
Adding Cursor IDE to the AI-Powered IDEs section.

## Why
Cursor is a popular AI-first code editor built on VS Code with native AI integration.

## Checklist
- [x] Link is working
- [x] Description is clear and concise
- [x] Follows existing format
- [x] Resource is actively maintained
```

## What NOT to Contribute

Please avoid:

- **Promotional content**: Don't add your own product unless it genuinely fits and has community validation
- **Duplicates**: Check if the resource already exists before adding
- **Outdated resources**: Tools/sites that haven't been updated in over a year
- **Broken links**: Always test links before submitting
- **Vague descriptions**: Provide specific information about what the tool does
- **Off-topic content**: Stay focused on AI-driven development
- **Affiliate links**: Use clean URLs without tracking parameters

## Removing Entries

If you notice an entry that is:
- No longer maintained
- Link is permanently broken
- No longer relevant
- Duplicate

Please open a pull request to remove it with an explanation.

## Suggesting New Sections

Have an idea for a new section? Great! Open an issue first to discuss:

1. Propose the new section name
2. Explain why it's needed
3. Provide 3-5 examples of entries that would fit
4. Describe how it differs from existing sections

## Code of Conduct

- Be respectful and constructive
- Welcome newcomers and help them contribute
- Focus on what is best for the community
- Show empathy towards other community members
- Accept constructive criticism gracefully

## Questions?

If you have questions about contributing:

1. Check existing issues and pull requests
2. Open a new issue with the "question" label
3. Reach out to the maintainers

## Recognition

All contributors will be recognized in the repository. Your contributions help the entire AI-driven development community!

Thank you for contributing! 🚀
